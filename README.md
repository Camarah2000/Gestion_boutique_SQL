# 🛒 Gestion_boutique_SQL

## 📌 Présentation du projet

Ce projet a pour objectif de mettre en pratique les connaissances acquises dans le cadre de mon apprentissage du langage SQL, à travers la création et la gestion d'une base de données pour une boutique commerciale.

Il m'a permis de découvrir et de manipuler les différentes fonctionnalités du langage SQL, depuis la conception d'une base de données jusqu'à l'extraction et l'analyse des informations.

## 🛠️ Travaux réalisés

Dans le cadre de ce projet, j'ai réalisé les différentes étapes suivantes :

- Création d'une base de données avec SQLite.
- Création des différentes tables.
- Définition des clés primaires (PRIMARY KEY).
- Mise en place des clés étrangères (FOREIGN KEY).
- Application des contraintes d'intégrité.
- Insertion de données dans les différentes tables.
- Rédaction et exécution de requêtes SQL pour extraire des informations.
- Utilisation des jointures pour relier plusieurs tables.
- Utilisation des fonctions d'agrégation pour effectuer des calculs et analyser les données.

## 📚 Compétences développées

À travers ce projet, j'ai pu mettre en pratique plusieurs notions SQL :

- SELECT, FROM, WHERE
- ORDER BY, GROUP BY, HAVING
- INNER JOIN
- COUNT(), SUM(), AVG(), MAX()
- Sous-requêtes
- Gestion des clés primaires et étrangères
- Contraintes d'intégrité

## 🎯 Objectif

Ce projet représente une étape dans mon apprentissage du SQL. Mon objectif est de renforcer mes compétences en manipulation de bases de données relationnelles et de progresser dans l'analyse de données.
